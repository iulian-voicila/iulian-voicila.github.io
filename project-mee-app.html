MEE, a bilingual learning application for Electrical and Electronic Measurements

Google PlaySource codeZenodo record

Overview

MEE is a learning application in Romanian and English for the second-year course Electrical and Electronic Measurements (Măsurări Electrice și Electronice). It offers short lessons on a progress map, spaced repetition of the student’s mistakes and a timed exam simulation. Finished modules unlock a virtual instrument bench.

Every figure is drawn by the application from the exercise data: analogue meters with needle and scale, oscilloscope screens, Wheatstone, Wien and De Sauty bridges, wattmeter connections (including the Aron method), operational-amplifier circuits and instrument transformers. Formulas are typeset with native MathML. The app works offline and collects no data.

The source code is public. The question bank is not distributed, because the exercises are also used for assessment; a demo module ships with the code so that it builds and runs after cloning.

My role
